# lukian-email

Imagini publice pentru emailurile Lukian. Conține doar materialele de campanie, care oricum sunt trimise public.

- `oferta-lansare/`: emailul „Ofertă de lansare” (plata lunară 10 € / lună / cont, plata anuală 120 € / an cu 5 agenți).

Sursa emailurilor e în repo-ul privat `lukian-studio` (`email/oferta-landing`).
